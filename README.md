# Shahbaz Ali — Android Developer Portfolio

Static website ready for GitHub Pages. No build step or dependencies.

## Publish
1. Create a public GitHub repository named `shahbazali80.github.io` (or use your existing Pages repo).
2. Upload **the contents of this folder** into the repository root, so `index.html` is at the top level.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.

## Images
All images are under `images/<app-name>/1.webp` through `5.webp`.
The homepage uses `1.webp` as the cover. Each project detail page shows up to five screenshots.
The Live GPS Earth Satellite Maps project currently has no supplied screenshots, so its homepage card uses the decorative fallback and its detail page explains that images are missing.

## Layout
- `index.html`: homepage
- `apps/`: 7 case-study pages
- `assets/`: CSS and screenshot gallery JavaScript
- `images/`: only images actively used on the site (WebP)

## Notes
- Don't upload private Android source code, client credentials, or confidential company material.
- All case-study text should reflect authorized professional work.
